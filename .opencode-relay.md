## ProtonPlus 0.6.0 build fix (THIS RUN - root-caused, patched, verified)
Root causes (upstream origin/main still broken; local patches required):
1. valac >= 0.56 passes \u001f/\u001e/\u007f control-character escapes verbatim into
   generated C; gcc rejects "not a valid universal character". Files: steam-change-receipt,
   steam-configuration-service, steam-restart-state-store (patch committed 6266eca
   previous window), PLUS tests/steam_test.vala:122/190 (0x7f ELF magic) - extended this run.
   NOTE: \x7f must be followed by string concat ("\x7f" + "ELFfixture"), NOT \x7fELFfixture,
   because \x7fE is a greedy hex escape that valac rejects as out-of-range.
2. system.vala [CCode(cheader_filename="utils/cpu-probe.h")] on struct CpuFeatureProbe
   makes valac emit BOTH its own struct body AND #include cpu-probe.h -> redefinition
   in system.c. Fix: fix-cpu-probe-struct-redef.patch drops cheader_filename (valac then
   emits self-contained struct + extern; byte-identical layout, verified with valac 0.56.16).
